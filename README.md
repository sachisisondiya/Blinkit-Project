# 🛒 Blinkit Sales Analysis Dashboard | Power BI Project

## 📌 Project Overview

This Power BI Dashboard provides a detailed analysis of Blinkit's sales performance, customer preferences, outlet distribution, and product categories. The dashboard is designed to help businesses make data-driven decisions by transforming raw retail data into actionable insights through interactive visualizations.

---

## 🎯 Business Objectives

- 📈 Analyze overall sales performance.
- 🏪 Evaluate outlet performance based on size and location.
- 🛍️ Identify top-performing product categories.
- 🥗 Understand customer preferences based on fat content.
- 📅 Analyze sales trends across outlet establishment years.
- 🎯 Support strategic business decision-making.

## 📈 Dashboard Insights

### 🏪 Outlet Size Analysis
- Large outlets contribute the highest percentage of total sales.
- Medium and small outlets generate comparatively lower sales.

### 📍 Outlet Location Analysis
- Tier 3 outlets generate the highest revenue.
- Tier 2 outlets perform moderately.
- Tier 1 outlets contribute the least sales.

### 🥗 Fat Content Analysis
- Regular fat products dominate total sales.
- Low-fat products contribute a smaller share.

### 🛍️ Item Type Analysis
Top-performing categories include:
- Fruits & Vegetables
- Snack Foods
- Household Items
- Frozen Foods
- Dairy Products

### 📅 Outlet Establishment Trend
- Sales performance varies across establishment years.
- Recently established outlets show strong growth trends.

### 🏬 Outlet Type Analysis
- Supermarkets contribute the majority of sales.
- Grocery stores maintain a significant market share.
